# Cookie 身份验证说明

应用支持两种 Cookie 使用方式：从浏览器临时读取，或读取由用户自行导出的 Netscape `cookies.txt` 文件。Cookie 能代表已登录会话，可能允许访问受账户保护的内容；请像保管密码一样保管它。

## 导出 Cookie 文件

1. 仅在自己的浏览器账号和有权访问的内容范围内使用 Cookie。
2. 使用可信的浏览器扩展或本地工具，将所需网站的 Cookie 导出为 Netscape `cookies.txt` 格式。
3. 在应用的“身份验证”设置中选择该文件。
4. 不要把 Cookie 文件上传到议题、聊天记录、网盘公开链接、构建日志或版本发布附件。
5. 不再需要时，请从本机安全删除导出的文件；如怀疑泄露，应立即在相应网站退出所有会话、修改密码并撤销会话。

不同网站、浏览器和扩展的界面会变化。本项目不会收集、上传或代管用户的 Cookie。

## 支持的浏览器读取方式

应用可尝试从下列浏览器配置中读取本机 Cookie：Brave、Chrome、Chromium、Edge、Firefox、Opera、Safari、Vivaldi 和 Whale。实际支持取决于操作系统、浏览器版本、权限、加密方式和目标网站。

若自动读取失败，可改用上面的 `cookies.txt` 文件方式。请先完全关闭可能锁定 Cookie 数据库的浏览器，并仅处理自己控制的本地资料。

## 常见问题

- Cookie 失效、退出登录或网站要求额外验证时，需要重新登录并导出新的文件。
- 应用无法绕过网站访问控制、付费限制、验证码或内容权利限制。
- 使用 Cookie 前，请确认符合网站条款、所在地法律和内容权利人的授权范围。
