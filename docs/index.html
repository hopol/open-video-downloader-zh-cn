简介

Open Video Downloader 简体中文维护版是独立维护的跨平台桌面应用，可从数百个受支持的网站下载视频、音频、字幕和元数据，不限于 YouTube。

本项目基于上游 Open Video Downloader 维护，但不属于上游官方发行。应用自身不使用自动更新或错误遥测；请仅从本项目的 GitHub 发布页面手动下载新版并校验 SHA-256 摘要。

运行环境

  • Windows：可能需要 Microsoft Visual C++ 可再发行组件。
  • macOS：系统通常自带 Python。
  • Linux：系统通常已安装 Python。
